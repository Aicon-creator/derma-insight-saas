Templates contain column headings only. Add your own records, keep the headings, and save as UTF-8 CSV. Upload up to 1,000 data rows and 5 MB per file.

Required columns and accepted values

Customers: email, first name, last name, skin type, concern. Every value is required. Skin types: oily, dry, combination, normal, sensitive. Concerns: acne, hyperpigmentation, aging, dullness, texture, hydration. Duplicate emails in one file block the import.

Products: name, category, price. Categories: cleanser, moisturizer, serum, sunscreen, treatment, toner, mask, other. Price must be a number of 0 or more, without a currency symbol.

Events: event type, customer email, product name, occurred at, amount. Event types: view, add_to_cart, purchase. Use the actual event date/time in YYYY-MM-DDTHH:mm:ssZ format, or with an explicit timezone offset. For purchases, amount is the price paid per unit, including any discount; quantity defaults to 1. For views and add-to-cart events, leave amount blank or use 0.

Optional event columns: event id, quantity, currency, session id. Use a stable, unique event ID from your source when available. Quantity must be a positive whole number. Currency defaults to GBP; only GBP is supported.
